Repo: takeover-defense · Environment: `takeover-defense` (Trusted, empty setup script) · Day: D0 · Time box: 30 minutes · Credit cap: $3

## Goal
Confirm that every file of the hub starter kit arrived intact, run the environment probe and explain its output in plain English, and record the first real credit cost so the caps for every later session can be sanity-checked. This session cannot check the four track repos — a cloud session only sees the repo it was started in — so each track checks its own kit in its first session (T1-S01, T2-S01, T3-S01, T4-S01).

   `CLAUDE.md`, `README.md`, `COSTS.md`, `AI-USE.md`, `LICENSE`, `.gitignore`, `.claude/agents/builder.md`, `.claude/agents/verifier.md`, `.claude/agents/chores.md`, `.claude/agents/redteam.md`, `.github/workflows/ci.yml`, `scripts/probe.sh`, `docs/CAVEATS.md`, `docs/RUN-SHEET.md`, `docs/MASTER-RUN-SHEET.md`, `docs/STORY.md`, `docs/verify/.gitkeep`, `docs/learning/.gitkeep`, `docs/briefs/H00.md`, `docs/briefs/H01.md`, `docs/briefs/H99.md`.

3. Director: run `probe` — `bash scripts/probe.sh >> docs/PROBES.md` (the script prints its own `## Probe <UTC time>` header). Then append one extra line below it, without editing `probe.sh`: `- reach https://github.com/ -> HTTP $(curl -s -o /dev/null -w '%{http_code}' --max-time 10 https://github.com/)` — GitHub is the fallback download source for Keycloak in the Track 1 and Track 3 environment setup.
4. Director: under the probe output add `### What each line means` — one plain sentence per line. For the `reach` lines: any 2xx/3xx/4xx code means the host answered (reachable); `000` means the connection was blocked or timed out.
5. Director: add `### What this means for the tracks`, quoting the probe values:
   - Track 2: the Kusto emulator needs `arch: x86_64` **and** `avx2 flags` greater than 0. State yes/no. If no, append a caveat line now (impact: T2-S02; needs Eojin: yes) so Track 2 plans its fallback before D2.
   - Track 1 and 3: Keycloak is downloaded by the environment setup from `repo1.maven.org` (HTTP 200 expected) with GitHub as fallback. State whether at least one is reachable. `keycloak: not installed` and `pwsh: not installed` are expected here because the hub uses the Default environment.
   - Note the assumption that the track environments run on the same machine class as this one; T1-S01 and T2-S01 re-run `probe` to confirm.
6. Director: ask Eojin for the balance before and after; `chores` replaces the `(example)` line in `COSTS.md` with the real H00 line and adds a one-line calibration note: spent vs cap $3, and whether the caps in `docs/MASTER-RUN-SHEET.md` look right, low or high.
7. `verifier`: check every acceptance criterion below; write `docs/verify/H00.md`.
8. `wrap`: update `docs/RUN-SHEET.md` (H00 → DONE), `AI-USE.md` (H00 section), `docs/CAVEATS.md`; push branch `h00-calibrate`; print the PR title and body.

- The Trusted network level blocks PowerShell Gallery, graph.microsoft.com and management.azure.com by design; their `reach` lines should show `HTTP 000`.
- A hub session cannot see the track repos; kit checks for them happen in each track's first session.
- `gitleaks/gitleaks-action@v3` runs free on a personal GitHub account; it would need a licence key if the repos were ever moved into an organisation (`TODO(verify)` only if that happens).
- Credit caps are planning numbers; this session's real spend is the first calibration point.
